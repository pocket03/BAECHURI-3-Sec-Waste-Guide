## 1. 문제 정의

대학가 원룸촌에 거주하는 외국인 유학생이 한국 특유의 종량제·분리배출 제도를 언어 장벽 때문에 이해하지 못해 무단투기·오배출이 반복되는 문제가 있다.

- **문제의 실재성**: 뉴스에서 "'분리수거 문법' 모르는 외국인 유학생…원룸촌마다 '쓰레기 전쟁'"으로 보도되었고[^1], 서울시 시민제안 게시판("민주주의 서울")에도 "대학교 근처 원룸가 쓰레기 무단투기 해결"이 정식 제안으로 등록되어 있다[^2].
- **근본 원인**: 외국인 대부분의 출신국에는 한국식 종량제·재활용 세분류 제도가 없어 생소하며, 실제 분리수거장에는 러시아어·우즈벡어·태국어·몽골어·베트남어·중국어 등 다양한 언어의 쓰레기가 뒤섞여 발견된다는 보도가 있다[^3].
- **기존 대응의 한계**: 서울시는 분리배출 요령을 6개국어로 번역해 제공하지만 정적 텍스트 페이지에 불과하고[^4], 일부 대학은 자체적으로 영문 PDF를 만들어 게시하는 수준에 머물러 있다[^5] — 자세한 근거는 [경쟁사 분석](외국인유학생분리배출가이드-경쟁사분석_20260810.md) 참고.

## 2. 타깃 사용자

| 구분 | 내용 |
|---|---|
| 1차 타깃 | 대학가 원룸촌에 거주하는 외국인 유학생 |
| 2차 타깃 | 원룸촌 인근 외국인 근로자·거주자, 임대인·관리사무소(현장 QR 부착 주체) |
| 잠재 규모 | 국내 외국인 유학생 25.3만 명(2025년, 교육부·한국교육개발원 — 전년 대비 21.3% 증가), 정부는 2027년까지 30만 명 유치 목표[^6] |

## 3. 핵심 가치 제안

> "복잡한 한글 분리배출 규정을, 사진만 보고 골라도 내 언어로 3초 안에 알려주는 서비스"

- **언어 장벽 없는 검색**: 정확한 한글 품목명을 몰라도 아이콘/사진을 보고 선택하면 결과가 나오는 구조.
- **현장 즉시 확인(QR)**: 분리수거장에 부착된 QR을 스캔하면 앱 설치 없이 웹에서 바로 그 장소의 배출 규정을 확인.
- **저사양 접근성**: 백엔드·로그인 없이 정적 데이터 + 웹으로 구현해 어떤 기기에서도 즉시 접근 가능.

## 4. 핵심 기능 (MVP 범위)

4주 제약과 언어 장벽 문제의 본질(정확한 검색어를 모른다는 것)을 고려해 다음 범위로 한정한다.

1. **아이콘/사진 기반 품목 검색** — 자취생 원룸촌 빈출 품목 20~30개(예: 배달 용기, 택배 박스·테이프, 일회용컵, 음식물 쓰레기 등)를 사진 그리드로 제공, 텍스트 검색은 보조 기능으로만 둠
2. **다국어 지원(2~3개 언어)** — 한국어 + 영어 + (중국어 또는 베트남어 중 대상 대학 유학생 비율이 높은 언어 1개, 통계 확인 후 확정)
3. **QR 현장 가이드 웹페이지** — 분리수거장별 QR 코드 생성(쿼리 파라미터로 장소 식별) → 스캔 시 해당 장소의 배출 요일·규정을 인포그래픽으로 표시
4. **인포그래픽 카드 UI** — 텍스트 최소화, 그림·아이콘 중심으로 3초 내 이해 가능한 카드 디자인

**MVP 제외 범위(향후 확장)**: 실시간 카메라 인식(AI 분류), 위치 기반 지도, 주민 제보 게시판, 다국어 4개 이상 확장 — 백엔드·로그인이 필요한 기능은 모두 4주 범위 밖으로 명확히 제외.

## 5. 차별화 포인트 (경쟁사 대비)

경쟁사 분석([외국인유학생분리배출가이드-경쟁사분석.md](외국인유학생분리배출가이드-경쟁사분석_20260810.md)) 기준, 아래 조합을 모두 갖춘 국내 서비스는 확인되지 않았다:

| 축 | 우리 서비스 | 대표 경쟁 유형 |
|---|---|---|
| 인터랙션 | 아이콘 검색 + 즉시 결과 | 서울시·환경부 자료는 정적 텍스트/PDF |
| 현장 접근성 | QR 스캔으로 앱 설치 없이 즉시 확인 | My Seoul 등 종합 앱은 별도 설치·탐색 필요 |
| 특화도 | 원룸촌 유학생의 분리배출 문제에만 집중 | My Seoul은 여러 생활정보 중 일부 |
| 카테고리 검증 | 일본 지자체·GomiSense 등 해외 유사 카테고리가 이미 상용화되어 수요가 검증됨 | 국내에는 아직 직접 경쟁자 없음 |

## 6. 성공 지표 (KPI) — 4주 MVP 기준

과제 성격상 상용 KPI(DAU, 매출 등)보다 **실사용 적합성 검증 지표**를 우선한다.

- 검색 성공률: 테스트 참여자(가능하면 실제 유학생 2~3명)가 특정 품목을 아이콘만 보고 60초 이내에 찾아내는 비율
- 언어 전환 정상 동작률: 전체 콘텐츠에서 언어 전환 시 깨지거나 누락되는 항목 없는지
- QR 스캔 → 결과 표시까지의 시간: 3초 이내 목표
- 발표 임팩트: 심사에서 "언어 장벽"이라는 구체적 원인과 "검증된 사회문제"라는 근거가 전달되는지

## 7. 리스크 및 대응

| 리스크 | 대응 |
|---|---|
| 번역 품질이 부정확하면 서비스 신뢰도 자체가 무너짐 | 언어를 2~3개로 제한하고, 가능하면 해당 언어 원어민(교내 유학생, 어학당 등)에게 검수 요청 |
| 지자체·대학마다 분리배출 규정이 달라 일반화가 어려움 | 특정 대학가 원룸촌 1곳을 기준으로 스코프를 명확히 좁힘(예: 우리 학교 인근) |
| 4주 내 QR+검색+다국어를 모두 완성하기엔 콘텐츠 제작 시간 부족 | [개발 기획안](../개발/외국인유학생분리배출가이드-개발기획안_20260810.md)에서 3주차 말까지 기능 동결, 4주차는 번역 검수·QA·발표 준비에 배정 |
| 실제 배포(QR 부착, 유학생 커뮤니티 홍보)까지 이어지지 않을 가능성 | MVP 단계 목표를 "실제 배포"가 아닌 "개념 증명 + 발표용 데모 완성도"로 명확히 설정 |

## 8. 향후 확장 로드맵 (4주 이후, 참고용)

1. 언어 확대(태국어·몽골어 등, 서울시 6개국어 기준 참고)
2. GomiSense 사례처럼 AI 카메라 인식 기능 추가
3. 위치 기반 지도 + 주민 제보 게시판(백엔드·DB 필요, 팀 프로젝트 단계에서 고려)
4. 대학 국제처·다문화지원센터와 연계해 실제 QR 배포
