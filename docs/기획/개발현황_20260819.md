## 1. 지금까지 작업한 것

### MVP 핵심 기능 (PRD Must/Should 기준)
- 집주인 화면(`/`): 템플릿 5개(쓰레기 배출 2 · 퇴실 청소 1 · 원룸 공지사항 2) 선택 → 한/영/중/베 4개국어 조합 메시지 자동 생성, 카카오톡 발송용 전체 복사
- 세입자 화면: 언어 선택(`/guide`) → 오늘의 배출 신호등·FAQ 버튼형 챗·품목 30종 아이콘 검색(`/search`) → 결과 카드(`/result`, 품목/장소/공지 쿼리 파라미터로 분기)
- 집주인용 건물 QR·분리수거장 현장 QR 생성 및 다운로드
- 데이터: 품목 30종, UI 문자열, FAQ, 알림톡 템플릿 전부 4개 언어로 작성 완료

### 배포
- GitHub 저장소 2곳(개인용 `BAECHURI_404`, 팀 저장소 `BAECHURI-3-Sec-Waste-Guide`)에 코드 반영
- Vercel 배포 완료: `https://baechuri-404.vercel.app`

### 고도화 기능
- **집주인 자유 공지 작성 + 자동번역**: 정해진 템플릿 외의 공지를 한국어로 입력하면 Google Cloud Translation API로 영/중/베 3개 언어 즉시 번역 (로그인·저장 없이 그때그때 사용, 서버 API 라우트로 키 보호)
- **집주인 로그인**: Supabase Auth 기반 이메일/비밀번호 로그인. 단일 계정 데모 구조로, 공개 회원가입 없이 Supabase 대시보드에서 계정 직접 생성. `/admin`은 로그인해야만 접근 가능(proxy로 보호)
- **공지사항 추가·수정·삭제**: `/admin`에서 집주인이 공지 작성 → 저장 시 Google Translate로 3개 언어 자동 번역되어 Supabase DB에 저장. 목록에서 수정·삭제 가능, 공지별로 세입자용 링크·QR 자동 생성(`/result?custom=<id>`). 세입자는 로그인 없이 읽기만 가능하도록 RLS 설정(쓰기는 집주인만)
- **문자(SMS) 알림 — Mock 모드**: 세입자 전화번호+언어를 `/admin`에 등록해두면, 공지사항의 "문자로 발송" 버튼으로 이미 번역된 내용을 세입자 언어에 맞게 일괄 발송. 단, Solapi 발신번호 사전등록이 아직이라 실제 발송 대신 서버 로그에만 남기는 Mock 모드로 동작 중 (환경변수 3개만 채우면 코드 변경 없이 실발송 전환됨)
- 보안: API 키(구글 번역)는 서버 환경변수로만 사용해 클라이언트에 노출되지 않음, `.env*`는 전부 `.gitignore` 처리, Vercel 환경변수로 프로덕션 키 관리

## 2. 남은 작업

| 기능 | 내용 | 비고 |
|---|---|---|
| **문자 실제 발송 전환** | Solapi 발신번호 사전등록 완료 후 Vercel에 `SOLAPI_API_KEY`·`SOLAPI_API_SECRET`·`SOLAPI_SENDER_NUMBER` 등록 | 등록 심사(영업일 1~3일)가 관건. 코드는 이미 준비됨 |
| **FAQ 기능 추가** | 세입자가 자주 묻는 질문에 대한 기능 확장 | 현재는 4개 질문이 코드에 고정되어 있음(정적). 집주인이 직접 추가/수정할 수 있게 할지, 세입자가 새로운 질문을 남길 수 있게 할지 방향 논의 필요 |
| **세입자 → 집주인 문의 요청** | 세입자가 집주인에게 궁금한 점이나 요청 사항을 보낼 수 있는 기능 | 로그인 없는 세입자가 보낸 내용을 집주인이 `/admin`에서 확인하는 구조가 될 것으로 예상. 저장 위치(DB), 알림 방식(집주인이 언제 확인하는지) 결정 필요 |
| **반응형 화면(큰 화면/작은 화면)** | 데스크톱 등 큰 화면에서도 레이아웃이 어색하지 않도록 정리 | 지금은 모바일 중심(`max-w-2xl`)이라 큰 화면에서는 여백만 넓어지는 정도. 집주인·관리 화면은 PC에서도 쓸 수 있어야 하므로 우선순위 있음 |

## 3. 참고 — 현재 계정/환경변수

- Supabase 프로젝트: `https://ntoilgkmqqptuvhagfsu.supabase.co` (로그인/DB용) — `notices`, `tenants` 테이블 사용 중
- Google Cloud Translation API: 번역 기능용, Vercel 환경변수 `GOOGLE_TRANSLATE_KEY`로 등록됨
- Solapi (문자 발송): 아직 미등록. 발신번호 사전등록 완료되면 `SOLAPI_API_KEY`, `SOLAPI_API_SECRET`, `SOLAPI_SENDER_NUMBER` 세 개 등록 필요 (안 채워져 있으면 자동으로 Mock 모드)
- 실제 키 값은 이 문서에 적지 않음 — Vercel 프로젝트 환경변수 및 `.env.local`(로컬, git 미포함)에서 관리
- 테이블 생성 SQL: [notices_table.sql](notices_table.sql), [tenants_table.sql](tenants_table.sql)
