# Figma 디자인 가이드

현재 코드에 적용된 디자인(폴리싱 완료 버전)을 Figma로 가져오거나 다시 그릴 때 참고하는 문서입니다.
디자이너가 이 문서만 보고도 색상·폰트·간격·컴포넌트 패턴을 그대로 재현할 수 있도록 정리했습니다.

## 1. Figma로 가져오는 방법

### 추천: html.to.design 플러그인으로 실제 배포 사이트 가져오기
1. Figma에서 플러그인 `html.to.design` 설치
2. 가져올 URL: `https://baechuri-404.vercel.app` (배포된 실제 사이트)
3. 페이지별로 따로 가져오는 걸 추천 (한 번에 전체를 가져오면 레이아웃이 깨지기 쉬움)
   - `/guide`, `/search`, `/result?item=hetbahn-container` 등 각각 캡처
   - 집주인 대시보드는 로그인이 필요해서 플러그인이 못 들어감 → 아래 "화면 인벤토리"의 설명과 스크린샷을 보고 수동으로 재현하는 걸 추천

**한계**: 이 플러그인은 "가져오기"만 되고 Figma에서 수정한 걸 다시 코드로 자동 반영하는 기능은 없습니다.
Figma에서 디자인을 다듬은 다음, 바뀐 부분을 개발자에게 알려주면 코드에 반영하는 방식(단방향)으로 진행하면 됩니다.

### 대안: 이 문서의 토큰/패턴을 보고 Figma에서 처음부터 그리기
가져오기가 잘 안 되거나 깨질 경우, 아래 2~4번 섹션의 값을 그대로 Figma 스타일로 등록해서 컴포넌트를 새로 만들면 됩니다.

## 3. 공통 컴포넌트 패턴

### 카드 (기본 단위)
```
배경: 흰색
테두리: 1px solid neutral-200
모서리: rounded-2xl (세입자 큰 카드는 rounded-3xl)
그림자: shadow-sm
내부 패딩: 16~24px
```

### 버튼
- **기본(초록, Primary)**: `green-600` 배경, 흰 텍스트, `font-semibold`, `rounded-lg`, hover 시 `green-700`
- **보조(테두리만)**: 흰 배경, `neutral-300` 테두리, `neutral-600` 텍스트
- **텍스트 링크**: 텍스트만, `green-700` 색, 밑줄(`underline-offset-2`)
- **삭제/위험**: 텍스트 링크, `red-600` 색

### 배지(Badge)
- 답변완료/재활용가능 등 "긍정" 상태: `green-100` 배경 + `green-800` 텍스트, `rounded-full`
- 미답변/주의 등 "대기" 상태: `amber-100` 배경 + `amber-800` 텍스트, `rounded-full`

### 헤더 (세입자 화면 공통 — `TenantHeader`)
- 좌측: 🥬 이모지 + "배추리 매니저" 브랜드 텍스트 + (선택) 페이지 제목
- 우측: 언어 선택 스위처(국기 아이콘, 4개 언어)

### 탭 내비게이션 (집주인 대시보드)
- 가로 스크롤 가능한 탭 목록, 각 탭은 이모지 아이콘 + 라벨
- 선택된 탭: 하단 2px `green-600` 밑줄 + `green-700` 텍스트
- 비선택 탭: `neutral-500` 텍스트, hover 시 `neutral-800`

### 아코디언 (FAQ)
- 닫힘: 흰 배경, `neutral-200` 테두리
- 열림: `green-600` 배경, 흰 텍스트, `shadow-sm`, 우측 화살표(▾) 180도 회전
- 답변: 말풍선 느낌으로 좌상단 모서리만 각짐(`rounded-tl-none`)

### 신호등 / 배너 (SignalLight)
- 재활용 가능일: 초록(`green-50` 배경, `green-300` 테두리) + 🟢
- 재활용 불가일: 빨강(`red-50` 배경, `red-300` 테두리) + 🔴
- 집주인이 배너 등록 시: 위 신호등 대신 주황(`amber-50`/`amber-300`) 공지 배너로 전환 (같은 자리, 같은 크기)

## 4. 화면 인벤토리

### 세입자 화면 (로그인 없음)

| 화면 | 경로 | 설명 |
|---|---|---|
| 언어 선택 | `/guide` | 4개 언어 버튼(한/영/중/베), 선택 시 `/search`로 이동 |
| 메인 검색 | `/search` | 상단 헤더 → 오늘의 배출 신호등(or 공지 배너) → FAQ 아코디언 → 품목 그리드(3~4열) → 문의하기 링크 |
| 품목 상세 | `/result?item=<id>` | 아이콘, 재활용 가능 여부 배지, 분리배출 방법, 주의사항, 배출 요일 |
| 장소 상세 | `/result?place=<id>` | 장소명, 설명, 받는 품목 태그 목록 |
| 공지 템플릿 | `/result?notice=<id>` | 집주인이 고른 정형 템플릿 공지 |
| 커스텀 공지 | `/result?custom=<id>` | 집주인이 직접 작성한 공지 (DB에서 로드) |
| 문의하기 | `/inquiry` | 전화번호 + 문의 내용 입력 → 제출 → 완료 화면 |

### 집주인 화면 (로그인 필요)

| 화면 | 경로 | 설명 |
|---|---|---|
| 로그인 | `/login` | 이메일 + 비밀번호 |
| 대시보드 — 발송 | `/` (발송 탭) | 알림톡 템플릿 선택 + 직접 작성/번역 + 미리보기 + 현장 QR |
| 대시보드 — 공지사항 | `/` (공지사항 탭) | 공지 작성(자동 3개국어 번역) + 저장 시 즉시 SMS 발송 + 목록/QR |
| 대시보드 — FAQ | `/` (FAQ 탭) | FAQ 작성/수정/삭제 (자동 번역) |
| 대시보드 — 문의 | `/` (문의 탭) | 세입자 문의 목록(한국어 번역본 표시) + SMS 답장(세입자 언어로 자동 번역) |
| 대시보드 — 세입자 | `/` (세입자 탭) | 세입자 전화번호·언어·메모 등록/삭제 |
| 대시보드 — 건물 설정 | `/` (건물 설정 탭) | 우리 건물 QR·링크 + 배출 요일/공지 배너 설정 |

## 5. Figma 파일 구조 제안

```
📄 Tokens        — 색상 스와치, 타이포 스타일, spacing/radius 가이드 (2번 섹션 내용)
📄 Components    — 카드, 버튼, 배지, 탭, 아코디언, 신호등 (3번 섹션 내용)
📄 세입자 화면    — guide / search / result(품목·장소·공지) / inquiry
📄 집주인 화면    — login / 대시보드 6탭
```

각 페이지 안에서 프레임 이름을 경로(`/search`, `/result?item=...`)로 붙여두면
개발자와 소통할 때 "어느 화면 얘기하는지" 바로 알 수 있어서 편합니다.
